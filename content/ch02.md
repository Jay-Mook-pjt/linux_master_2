## 📘 리눅스의 집 구조 (디렉토리)

리눅스는 윈도우처럼 C드라이브·D드라이브가 따로 있는 게 아니라, **"/" (루트)** 하나에서 나뭇가지처럼 뻗어나가는 **트리 구조**예요.

```
/
├── bin     ← 기본 실행 명령어들 (ls, cp 등)
├── boot    ← 부팅에 필요한 파일 (커널 이미지!)
├── dev     ← 장치 파일
├── etc     ← 시스템 설정 파일들
├── home    ← 사용자 홈 디렉토리
├── proc    ← 시스템 정보를 보여주는 "가상" 디렉토리
├── tmp     ← 임시 파일
└── var     ← 로그처럼 계속 변하는 데이터
```

### 꼭 기억해야 할 디렉토리별 함정

- **/proc**: 디스크가 아니라 메모리에서 시스템 정보를 실시간으로 보여주는 가상 디렉토리
- **/boot**: "커널이 들어있는 디렉토리는?" → 정답 **/boot**

> [!DANGER] 초강력 함정
> "/ 바로 밑에 있는 디렉토리가 **아닌** 것"을 고르는 문제에 **/include**가 자주 나와요. 리눅스 디렉토리 구조에 없는 이름입니다.
