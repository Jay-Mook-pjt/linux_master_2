## 📘 진짜 많이 쓰는 명령어들

리눅스 명령어는 짧은 영어 약자라서, 원래 뜻을 알면 외우기 쉬워요.

### 3-1. 파일 · 디렉토리 다루기

| 명령 | 원래 뜻 | 자주 쓰는 옵션 |
|------|---------|----------------|
| `pwd` | print working directory | 현재 위치 출력 |
| `ls` | list | `-a` 숨김파일, `-l` 상세정보 |
| `mkdir` | make directory | `-p` 중간 경로까지 한 번에 |
| `cp` | copy | `-r` 디렉토리째, `-i` 덮어쓰기 전 확인 |

### 3-2. 리다이렉션

```bash
ls -al > list.txt     # 덮어쓰기
echo "안녕" >> list.txt # 끝에 추가
ls -al | more         # 출력을 다음 명령의 입력으로
```

> [!TIP] 한 문장 정리
> `>`·`>>`는 출력을 파일로, `<`는 입력을 파일에서, `|`는 출력을 다음 명령으로.

### 3-3. 파일 권한 (chmod)

읽기(r)=4, 쓰기(w)=2, 실행(x)=1 을 더해요.

- `rwxr-xr--` → 7 5 4 → **754**
- `chmod 755 file` : 소유자 rwx, 그룹·기타 r-x
