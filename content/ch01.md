## 📘 이 템플릿 사용법 (작성 예시 모음)

이 챕터는 **글 쓰는 방법 예시**예요. 내용을 확인한 뒤 지우거나 내 내용으로 바꾸면 됩니다.
파일 위치: `content/ch01.md`

### 1-1. 제목 만들기

- `## 제목` → 챕터 제목 (목차에 크게 표시)
- `### 제목` → 소제목 (목차에 들여쓰기로 표시)
- 제목마다 `#sec-1`, `#sec-2` … 주소가 자동으로 붙어요. 원하는 주소를 쓰고 싶으면 제목 끝에 `{#my-id}` 를 붙이세요.

### 1-2. 글자 꾸미기 {#format}

**굵게**, *기울임*, `코드`, [링크](https://github.com) 를 쓸 수 있어요.

1. 번호 목록
2. 두 번째
   - 들여쓰면 하위 목록

### 1-3. 표 만들기

| 명령 | 뜻 | 설명 |
|------|----|------|
| `ls` | list | 목록 보기 |
| `cp` | copy | 복사 |
| `rm` | remove | 삭제 |

### 1-4. 코드(터미널) 박스

```bash
guest@study:~$ ls -al   # 숨김 파일까지 보기
guest@study:~$ pwd
/home/guest
```
